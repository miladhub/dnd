# Portrait attribution

These portraits were downloaded from [DMingDad's Free D&D Character Art](https://dmingdad.com/free-dnd-character-art/).

DMingDad states on that page that the character art is free to use for non-commercial purposes. The files are retained here for the same non-commercial use by this project:

- `caelri-berserker.png` — Caelri, human female berserker
- `tadga-goblin.png` — Tadga, goblin berserker
- `ilalea-goliath-knight.png` — Ilalea Steadyheart Veomaga, female goliath knight
- `character-69849197.webp` — source filename retained from DMingDad

`wolf.svg` is a small project-created vector portrait used for wolf encounters.

The following monster portraits were downloaded from [MythJourneys' free D&D monster art gallery](https://mythjourneys.com/gallery/dungeons-and-dragons/free-dnd-monster-art/), whose [About page](https://mythjourneys.com/about/) states that the site images are free to use under its unofficial fan-content terms:
